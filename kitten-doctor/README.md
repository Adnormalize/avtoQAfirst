# Доктор для котёнка

Детская HTML5-игра: лечим чёрного котёнка. Русский интерфейс, крупные кнопки, работает офлайн как статика.

## Запуск локально

Из папки `kitten-doctor/`:

```bash
# любой статический сервер, например:
python3 -m http.server 8080
```

Откройте в браузере: http://127.0.0.1:8080/

Или просто откройте `index.html` двойным кликом (шрифты с Google Fonts потребуют сеть; сама игра работает и без них).

## Механика

1. **Осмотр** — найди больную лапку (тап по лапке).
2. **Помыть** — возьми мыло → нажми на лапку.
3. **Лекарство** — возьми бутылочку → нажми на котёнка.
4. **Пластырь** — возьми пластырь → нажми на лапку.
5. **Покормить** — нажми на миску.
6. **Победа** — котёнок здоров; можно начать снова.

## Яндекс Игры

- `js/yandex-sdk-stub.js` — заглушка `YandexGamesBridge` (gameReady / gameplayStart/Stop).
- Реклама отключена (`ads.enabled = false`), вызовов SDK-рекламы нет.
- Для публикации: подключите официальный `/sdk.js` и замените заглушку на `YaGames.init()` без рекламных вызовов, пока не решите иначе.
